รายการงานที่ยังไม่ปิดทั้งหมด

เรียงจากค้างนานที่สุด · เกินเป้า = ค้างนานกว่าเวลามาตรฐานที่เสนอของงานประเภทนั้น

  1. 1. ล้างงานค้างเก่า

    ให้ทุกทีมยืนยันสถานะงานที่ยังไม่ปิด แยกเป็น ซ่อมแล้วแต่ไม่ได้ปิด / รอวัสดุ / รอหน่วยงานอื่น / ยังไม่ได้เข้า เริ่มจากงานน้ำไม่ไหลของทีม.ประปากระบี่

    ภายใน 3 วันทำการ · หัวหน้างานบริการฯ
  2. 2. ปรับทะเบียนให้ติดตามได้

    บังคับกรอกวันที่ซ่อมแล้วเสร็จ (คอลัมน์ V ยังว่างทุกแถว) เพิ่มช่องสาเหตุที่ค้าง และทำสถานะเป็นตัวเลือก เพื่อวัดเวลาซ่อมจริงได้

    ภายในสัปดาห์นี้ · ผู้ดูแลทะเบียน
  3. 3. เวลามาตรฐานและการยกระดับ

    ค้างเกิน 3 วัน หัวหน้างานติดตามและรายงานเหตุผล · เกิน 7 วัน รายงานผู้ช่วยผู้จัดการ · ผู้รับจ้างเกินกำหนด ทำหนังสือเร่งรัดตามเงื่อนไขสัญญา

    ประกาศใช้หลังเทียบเกณฑ์ กปภ. และสัญญา
  4. 4. จังหวะการติดตาม

    ทุกเช้าส่งรายการงานเกินกำหนดแยกทีมทาง LINE · ทุกวันศุกร์ปิดสถานะงานของสัปดาห์ · ทุกวันจันทร์สรุปเสนอผู้จัดการสาขา

    เริ่มทันที · ผู้ช่วยผู้จัดการ

เวลามาตรฐานที่เสนอ

ใช้คำนวณ "เกินเป้า" ในหน้านี้ · เป็นข้อเสนอเบื้องต้น ยังไม่ใช่เกณฑ์ทางการ

ประเภทงานเป้าหมายปิดงานงานค้างที่เกินเป้า
